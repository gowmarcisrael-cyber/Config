Politique de confidentialité

Dernière mise à jour : juin 2025

HAVEN s'engage à protéger la vie privée de ses utilisateurs. Cette politique explique quelles données nous collectons, comment nous les utilisons et quels sont vos droits.

1 Données collectées

Nous collectons les données suivantes lors de votre utilisation de HAVEN :

  • → Informations d'identification : nom d'utilisateur, adresse email, mot de passe (chiffré)
  • → Informations de profil : prénom, nom, photo de profil, numéro de téléphone
  • → Données des annonces : titre, description, localisation, photos, prix
  • → Données de navigation : adresse IP, type de navigateur, pages visitées
  • → Communications : messages de contact, demandes de visite

2 Utilisation des données

  • → Gérer votre compte et authentifier votre identité
  • → Publier et gérer vos annonces immobilières
  • → Faciliter les demandes de visite entre utilisateurs
  • → Envoyer des notifications et emails transactionnels
  • → Améliorer nos services et détecter les fraudes
  • → Respecter nos obligations légales

3 Partage des données

Nous ne vendons jamais vos données personnelles. Nous pouvons les partager uniquement avec :

  • → D'autres utilisateurs HAVEN — uniquement les informations nécessaires aux transactions (nom, contact pour les visites)
  • → Prestataires techniques — hébergement, email (sous contrat de confidentialité)
  • → Autorités légales — uniquement sur demande judiciaire

4 Cookies

HAVEN utilise des cookies essentiels au fonctionnement du site :

  • → Cookie de session — maintient votre connexion
  • → Cookie CSRF — protège contre les attaques

Nous n'utilisons pas de cookies publicitaires ou de tracking tiers.

5 Vos droits

Vous avez le droit de :

  • → Accéder à vos données personnelles
  • → Corriger vos informations depuis votre profil
  • → Supprimer votre compte et vos données
  • → Vous opposer au traitement de vos données
  • → Exporter vos données

6 Conservation des données

Vos données sont conservées tant que votre compte est actif. Après suppression de votre compte, vos données sont effacées dans un délai de 30 jours, sauf obligation légale de conservation.

7 Sécurité

Nous utilisons des mesures de sécurité adaptées — chiffrement HTTPS, mots de passe hachés, protection CSRF, accès restreint aux données sensibles. Cependant aucun système n'est infaillible.

8 Contact

Pour toute question concernant vos données personnelles :
